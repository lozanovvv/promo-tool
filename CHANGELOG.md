# Changelog

## Последняя версия
- Новый дизайн .dmg: тёмный фон, стрелка, ярлык Applications, иконка приложения
- Иконка приложения (macOS/Windows)
- Структура архива: `src` (код) и `app` (готовые .exe и .dmg)
- Шаблон больше не лежит внутри (лимит GitHub): скачивается с Google Диска при первом запуске, ссылка в `config.py`
- Верхняя надпись теперь тем же стилем, что оригинальная RMRP (жирный курсив Montserrat Black Italic)
- Убрано синее «пятно» под звездой и за новой надписью (остатки старых букв)
- Своя звезда: нарисованная «шашечка» или белый фон картинки вырезается автоматически
- Видео выбирать не нужно (кнопка «Другое…» — своё видео)
- При запуске заполнено только «RMRP», сервер и промокод пустые
- Убраны приписки «(было …)» у полей
- Предупреждение, если сервер или промокод не заполнены
- Смена звезды: оригинал / убрать / своя PNG-картинка (CLI: `--star none` или `--star файл.png`)
- README обновлён

## Раньше
- Новый интерфейс на CustomTkinter по дизайну: экраны «главный», «рендер», «готово»
- Исправлено положение текста этапов на экране рендера
- Прогресс распаковки кадров и кнопка «Отменить»
- Надписи любой длины уменьшаются пропорционально, без «карлика»
- Исправлены серые подтёки под «ПРОМОКОД» и остатки старых букв
- Замена RMRP (сверху), названия сервера, промокода и цвета (8 пресетов + свой)
- Сборки: Windows `.exe`, macOS `.dmg` (Apple Silicon и Intel) через GitHub Actions или скрипты
- Скрипты для Mac создают `.venv` (ошибка externally-managed-environment)
