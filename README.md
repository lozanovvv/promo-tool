# PromoTool

Программа для быстрой замены текста, цвета и звезды в промо-заставке (ProRes 4444 с прозрачностью, 2560×1440).
Шаблон скачивается сам при первом запуске: вводишь новый текст, выбираешь цвет — получаешь готовый ролик. Никакого ручного монтажа.

*A small desktop tool that swaps the texts and accent color in a neon promo-code intro video, keeping the original animation and alpha channel.*

## Возможности

- Замена **большой надписи сверху** (было `RMRP`) — с анимацией появления и исчезновения
- Замена **названия сервера** (было `ТВЕРСКОЙ`)
- Замена или удаление **звезды** над надписью: оригинал, убрать или своя PNG-картинка
- Замена **промокода** (было `KLA4`) в том же неоновом стиле
- **Смена цвета** всей заставки: 8 пресетов или любой свой
- Длинные надписи сами уменьшаются, сохраняя пропорции
- Живой предпросмотр прямо в окне и быстрая проверка двух реальных кадров перед рендером
- Прогресс рендера и кнопка «Отменить»
- Результат: `.mov` (ProRes 4444 + альфа) и по желанию лёгкое `.mp4`-превью

## Установка

Готовые сборки: вкладка **Actions → build → Artifacts**
(`PromoTool.exe` для Windows, `.dmg` для macOS Apple Silicon и Intel).

Из исходников (Python 3.10+ с tkinter):

```bash
# Windows
run.bat

# macOS
./run_mac.command
```

Своя сборка: `build.bat` (Windows) или `build_mac.command` (macOS, красивый установщик с иконкой и фоном). Готовые `PromoTool.exe` и `PromoTool.dmg` складываются в папку `app` рядом с `src`.

## Использование

1. Шаблон скачается сам при первом запуске (нужен интернет), видео выбирать не нужно (кнопка «Другое…» — если хочешь своё)
2. Введи промокод, надпись сверху и название сервера
3. Выбери цвет и, если нужно, звезду
4. Нажми «Предпросмотр», затем «Сделать видео»

Командная строка:

```bash
python app.py in.mov out.mov --brand RMRP --server НАЗВАНИЕ --promo КОД --hue 222 --star none      # или --star свой.png
```

## Шаблон (Google Диск)
Файл шаблона (~97 МБ) не лежит в репозитории из-за лимита GitHub. Программа сама скачивает его при первом запуске и кеширует.

1. Загрузи `template.mov` на Google Диск → «Настроить доступ» → **«Все, у кого есть ссылка»** (читатель)
2. Вставь ссылку в `config.py`: `TEMPLATE_URL = 'https://drive.google.com/file/d/…/view'`
3. Собери программу как обычно

Без пересборки: положи ссылку в файл `template_id.txt` в папке данных программы (macOS `~/Library/Application Support/PromoTool/`, Windows `%APPDATA%\PromoTool\`) или задай переменную `PROMOTOOL_TEMPLATE`.

## Ограничения

- Работает с одним шаблоном заставки (2560×1440); для другой раскладки нужна подстройка зон в `engine.py` (`SPECS`)
- Шрифт новых надписей — Unbounded Black (похож на оригинальный, но не идентичен)
- Мелкие оранжевые декоры (кружки, крестики) могут остаться оранжевыми
